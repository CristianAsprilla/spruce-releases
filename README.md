# Spruce

*Spruce up your PC.* A careful Windows cleaner, app updater and uninstaller.

## Download

Get **`Spruce_<version>_x64-setup.exe`** from the
**[latest release](https://github.com/CristianAsprilla/spruce-releases/releases/latest)**.
It installs for your user only — no admin prompt — and Spruce keeps itself up to date after that.

The installer isn't code-signed yet, so Windows SmartScreen may say *"Windows protected your PC"*:
choose **More info → Run anyway**. Each release lists the installer's SHA-256 in `SHA256SUMS.txt`,
and every update Spruce downloads is checked against its signing key before it runs.

This repository only holds Spruce's releases.
